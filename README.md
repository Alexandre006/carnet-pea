# Carnet PEA

Suivi de PEA installable sur iPhone (lignes, journal des opérations, poche espèces, dividendes, aide à l’investissement mensuel).

- L’app : `index.html` (publiée par GitHub Pages). Tes données restent sur ton appareil ; rien de personnel n’est stocké ici.
- Les cours : le robot `.github/workflows/cours.yml` récupère chaque jour de semaine les cours publics (Yahoo Finance) des valeurs de `data/universe.json` et `extra-tickers.txt`, et les publie dans `data/`.

Information et simulation uniquement : pas un conseil en investissement.
